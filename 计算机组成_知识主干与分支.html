02｜进制：同一个数量的不同写法

Week1-Lecture-Chapter1.pdf · PDF 第 6 页

进制决定每一位的权重。r 进制中，小数点左边依次是 r⁰、r¹、r²，小数点右边依次是 r⁻¹、r⁻²。二进制适合电路，十六进制把长位串压缩成便于人读的形式。

统一公式：数值 = Σ（该位数字 × r 的位次幂）。B 表示二进制后缀，H 表示十六进制后缀，D 表示十进制后缀；单位 B 又可能表示 byte，要按语境分辨。
  • 其他进制 → 十进制：按位权展开相加，如 9FH = 9×16+15 = 159。
  • 十进制整数 → r 进制：反复除以 r，记录余数，最后倒序写出。
  • 十进制小数 → 二进制：反复乘 2，依次取整数部分；不一定有限终止。
  • 二进制 ↔ 十六进制：以小数点为界，每 4 位一组；整数高位补 0，小数末尾补 0。八进制对应每 3 位一组。
  • 八进制 ↔ 十六进制：先把每个八进制数字换成 3 位二进制，再按 4 位重分组。

例如 101101.01₂ = 32+8+4+1+¼ = 45.25₁₀；其十六进制是 2D.4H。补 0 的方向必须保持位权不变。

03｜位宽、字长、容量与 C 数据类型

Week1-Lecture-Chapter1.pdf · PDF 第 46 页 Week1-Tutorial-Chapter1 with solution.pdf · PDF 第 23 页

bit 是一个二进制位，byte 是一组位；本课程按 1 byte = 8 bits 计算。字长描述处理器自然处理的数据宽度，数据总线宽度描述一次传送多少位，地址宽度描述可区分多少地址。这三个参数有联系，但不能相互替代。

名词本课用法容易混淆处
x86 BYTE / WORD / DWORD / QWORD8 / 16 / 32 / 64 bitsx86 的 WORD 固定为 16 位，与“64 位处理器的字长”不是同一个语境
K / M / G / T本课容量计算按 2¹⁰ / 2²⁰ / 2³⁰ / 2⁴⁰更严格写作 Ki / Mi / Gi / Ti；传输速率的 k、M、G 通常按十进制
n 位地址、按字节编址2ⁿ 个字节地址，范围 0 到 2ⁿ−1这是地址空间上限，不能直接当已安装 RAM 容量
N×w 存储器N 个存储单元，每单元 w 位总容量 Nw bits = Nw/8 bytes

C 类型大小由编译器目标和 ABI 决定。常见环境中 char 占 1 个 C 字节，short 16 位、int 32 位、long long 64 位；long 在不同 ABI 中可能为 32 或 64 位。64 位程序仍使用 32 位 int 很常见，这是数据模型的选择。指针宽度也不等于物理地址总线宽度。

#include <stdio.h>
#include <limits.h>
int main(void) {
    int a = 0;
    printf("int: %zu bits; pointer: %zu bits\n",
           sizeof(int)*CHAR_BIT, sizeof(void*)*CHAR_BIT);
    printf("int range: %d to %d; address: %p\n", INT_MIN, INT_MAX, (void*)&a);
    return 0;
}
独立局部变量的地址差和排列顺序没有统一答案；数组的相邻元素才保证连续。打印地址用 %p 并传入 void*。不要从屏幕上恰好显示的十六进制位数推断硬件物理地址宽度。

04｜编码：二进制整数、BCD 与 ASCII

Week1-Lecture-Chapter1.pdf · PDF 第 30 页 Week2-Lecture-Chapter1.pdf · PDF 第 6 页

位串本身不携带类型。解释规则确定后，数值才确定。01010011B 作为无符号整数是 83，作为 8 位补码仍是 83，作为压缩 BCD 是十进制 53，作为 ASCII 是字符 S。

编码规则例子
无符号整数所有位参与位权求和98H → 152
补码整数最高位权为 −2ⁿ⁻¹，其余位权为正8 位 98H → 152−256 = −104
压缩 BCD每 4 位独立表示一位十进制数字98H 表示十进制 98；AH–FH 不能是单个 BCD 数字
非压缩 BCD每字节保存一位十进制数字59 表示为 05H、09H 两个数字字节
ASCII7 位字符编码，常保存在 8 位字节中0–9:30H–39H；A–Z:41H–5AH；a–z:61H–7AH

大小写字母的 ASCII 差为 20H，即十进制 32。只对已确认是英文字母的字符进行加减：大写转小写加 20H，小写转大写减 20H。98H 不属于基本 7 位 ASCII。

05｜有符号数：原码、反码、补码

Week2-Lecture-Chapter1.pdf · PDF 第 9 页

给正负号留一位是原码的直观做法，但正零和负零会重复，运算也麻烦。反码把负数写成正数逐位取反；补码再加 1，使正负数都能用同一套模 2ⁿ 加法电路处理。

n 位格式正数负数 −m范围
原码 sign-magnitude符号位 0，数值位 m最高位 1，其余位保存 m−(2ⁿ⁻¹−1) 到 +(2ⁿ⁻¹−1)
反码 one’s complement与普通二进制相同对 +m 的全部 n 位取反同原码；也有两个零
补码 two’s complement与普通二进制相同2ⁿ−m，即取反加 1−2ⁿ⁻¹ 到 2ⁿ⁻¹−1；只有一个零
读取 n 位补码：最高位为 0 时照常读；最高位为 1 时，用“无符号值 −2ⁿ”。编码负数前必须先固定 n。

8 位 −24：+24 是 00011000；原码为 10011000，反码为 11100111，补码为 11101000。8 位补码 80H 表示 −128；原码和反码在 8 位下都无法表示 −128。

扩位要保留数值：无符号数在高位补 0；补码在高位复制符号位。8 位 EAH 是 −22，扩成 16 位是 FFEAH；扩成 00EAH 则变成 +234。

06｜补码运算、截断与溢出

Week2-Lecture-Chapter1.pdf · PDF 第 29 页

n 位加法器只保留结果的低 n 位，即对 2ⁿ 取模。减法 a−b 可改写为 a 加上 b 的补码相反数。硬件得到的低位结果完全确定；它是否等于心里期待的整数，要看位宽和解释范围。

  • 无符号加法超出 2ⁿ−1 时，进位 CF=1；有符号加法超出补码范围时，溢出 OF=1。
  • 加法 OF：两个同号数相加，结果符号相反。减法 OF：两个异号数相减，结果符号与被减数相反。
  • 8 位 7FH+01H=80H：CF=0，OF=1；FFH+01H=00H：CF=1，OF=0。
  • 要得到超出原范围的正确整数，必须先扩位再运算。结果截断后再扩位，无法恢复丢掉的高位。
  • 取相反数 NEG 等价于 0−x；最小负数在同位宽下没有可表示的正相反数，例如 NEG 80H 仍为 80H，OF=1。
C 语言与寄存器算术要分开：无符号 C 运算按其类型宽度取模；有符号算术溢出属于未定义行为，不能把某次运行中的回绕当作可移植规律。窄整数还可能先提升成 int。

07｜浮点数：用有效数字与指数表示范围

Selflearning -Foundation of floating point number.pdf · PDF 第 2 页

浮点数把一个数拆成符号、有效数字和指数，类似科学计数法。它用有限位数在很大的范围内近似表示数值；范围和精度是两回事。此材料明确标注为参考自学、无关联考核。

格式符号 S阶码 E小数域 F偏置
binary32 单精度1 位8 位23 位127
binary64 双精度1 位11 位52 位1023
正规格化数：x = (−1)ˢ × (1+F/2ᶠ) × 2^(E−bias)。小数域前隐含 1，f 为小数域位数。阶码用偏置表示，不用补码。
  1. 把绝对值换成二进制。
  2. 移动小数点，写成 1.xxx×2ᵉ。
  3. S 记录符号，E=e+bias；只把 xxx 放入小数域，补零或按舍入规则处理。
  4. 拼接 S、E、F，再每 4 位转换成十六进制。

例如 14=1.11₂×2³，因此单精度 S=0，E=130=10000010B，F=110…0，最终为 41600000H。

边界补充：E 全 0 时表示零或非正规格化数（隐含位改为 0，指数为 1−bias）；E 全 1 时为无穷或 NaN。十进制 0.1 在二进制中无限循环，因此浮点计算通常需要舍入。

08｜组合逻辑：门、布尔表达式与 ALU

Week3-Lecture-Chapter2.pdf · PDF 第 4 页

组合电路的当前输出只由当前输入决定。AND 像“同时满足”，OR 像“至少满足一个”，NOT 翻转真假，XOR 在输入不同时输出 1。ALU 把这些逻辑网络和算术网络放在一起，再用控制信号选择输出。

ABANDORXOR
00000
01011
10011
11110
  • 德摩根律：¬(AB)=¬A+¬B；¬(A+B)=¬A·¬B。加号在布尔代数里表示 OR，乘号表示 AND。
  • 吸收律：A+AB=A；分配律：A(B+C)=AB+AC。
  • SOP（积之和）：找真值表中输出为 1 的行，每行写一个最小项，再 OR。
  • POS（和之积）：找输出为 0 的行，每行写一个最大项，再 AND。最大项中某位输入为 0 时写原变量，为 1 时写反变量。
  • XOR 的 SOP 为 ¬A·B+A·¬B；POS 为 (A+B)(¬A+¬B)。

半加器：S=A⊕B，C=AB。全加器加入输入进位 Cin：S=A⊕B⊕Cin，Cout=AB+ACin+BCin。把多个全加器串联就能加多位整数。

NAND=NOT(AND)，NOR=NOT(OR)，XNOR=NOT(XOR)。两输入共有四种输入组合，每种组合输出可取 0/1，所以一共 2⁴=16 种二输入布尔函数。多输入 XOR 在输入的 1 个数为奇数时输出 1。

09｜译码器、编码器与多路选择器

Week3-Lecture-Chapter2.pdf · PDF 第 11 页

地址是一个二进制编号。译码器把编号变成“选中哪一条线”，因此适合选存储芯片；MUX 则从多条数据线中挑出一条送往输出，因此适合选寄存器或 ALU 输入。

部件输入 → 输出核心作用
n→2ⁿ 译码器 decodern 位编号 → 最多 2ⁿ 条选择线一个编号对应一个有效输出
2ⁿ→n 编码器 encoder有效输入线 → n 位编号普通编码器需保证单输入有效；优先编码器另有优先规则
2ⁿ→1 MUX2ⁿ 路数据+n 位选择 → 1 路数据选择信号决定哪路数据通过

74LS138 有 3 个选择输入和 8 个低有效输出。只有高有效使能 G1=1、两个低有效使能均为 0 时工作；其余情况所有 Y 输出为 1。正常工作时，输入编号为 k，Yk=0，其他 Y=1。

扩成 5→32 时，把高 2 位用于选 4 个组中的一个，把低 3 位并联到各组的 3→8 输入。输出编号 k = 8×组号 + 组内编号。输出和使能的有效极性要匹配；不能不看小圆圈就把“选中”写成高电平。

MUX 扩展也采用分层选择：8→1 可先让两个 4→1 分别选择低半组/高半组，再由最高选择位决定哪组输出；16→1 可用四个 4→1 做第一层、一个 4→1 做第二层，共五个。若把使能用作组选控制，必须确保输出结构允许连接，不能把普通推挽输出直接相连。

10｜寄存器与 x86 寄存器层次

Week4-Lecture-Chapter2.pdf · PDF 第 4 页

寄存器是 CPU 内部少量、快速的存储位置；与组合电路相比，它能记住前一时刻的状态。寄存器组提供多个可选择的存储位置，控制单元决定读哪几个、把结果写回哪一个。

层次或用途名称与作用
通用数据8086 的 AX、BX、CX、DX 均为 16 位，可拆成 AH/AL、BH/BL、CH/CL、DH/DL
指针与变址SP 栈顶、BP 基址；SI、DI 常用于数组或字符串
段寄存器CS 代码段、DS 数据段、SS 栈段、ES 附加段
程序控制IP 指令偏移；FLAGS 保存状态及控制位
取指和访存内部寄存器PC 定位后续指令，IR 保存当前指令，MAR 保存访存地址，MDR/MBR 暂存传送数据
扩展AX ⊂ EAX ⊂ RAX；FLAGS/EFLAGS/RFLAGS 分别为 16/32/64 位；64 位架构还增加 R8–R15 等

用户可见寄存器由指令直接操作；IR、MAR 等通常属于内部实现。浮点、向量、常量和专用寄存器属于不同用途分类，不应一概当成 8086 里存在的部件。

11｜六个状态标志与三个控制标志

Week4-Lecture-Chapter2.pdf · PDF 第 16 页

算术指令除写出结果，还会留下状态。判断标志时先固定操作数宽度，再计算截断结果；部分标志看完整运算，部分只看低位结果。

标志设置为 1 的条件判断范围
CF加法最高位进位；减法无符号借位完整运算与 n 位边界
OF有符号结果越界n 位补码解释
SF结果最高位为 1n 位结果
ZF截断后的结果为 0全部 n 位结果
AF低 4 位相加向 bit 4 进位，或相减从 bit 4 借位半字节边界
PF结果低 8 位含偶数个 1始终只看低字节；0 个 1 也是偶数
计算顺序：先结果 → CF、OF → SF、ZF → AF → PF。不能用 CF 代替 OF，也不能对 16 位结果的所有位计算 PF。
控制位含义
DF字符串指令方向：0 时 SI/DI 按元素宽度增加，1 时减少
IF控制可屏蔽外部中断 INTR；不负责屏蔽 NMI
TF单步跟踪，用于调试

DEBUG 的显示对照：OF=OV/NV，DF=DN/UP，IF=EI/DI，SF=NG/PL，ZF=ZR/NZ，AF=AC/NA，PF=PE/PO，CF=CY/NC（前者为 1，后者为 0）。MOV、LEA、普通 PUSH/POP 不修改算术状态标志；INC/DEC 保留 CF；AND 清 CF/OF，AF 未定义。

12｜存储组织：地址、内容与小端序

Week4-Lecture-Chapter2.pdf · PDF 第 33 页

地址相当于格子的编号，内容是格子里存的位。按字节编址时，一个地址对应一个字节；一个 16 位数会跨两个相邻地址。地址增加的方向与纸上从上往下画表格的方向没有必然联系。

x86 小端序 little-endian：最低有效字节放在最低地址。数值按高位到低位书写；内存按地址从小到大读取时，先看到低字节。
地址1000H1001H1002H1003H
字节内容78H56H34H12H

从 1000H 读取 8 位为 78H，读取 16 位为 5678H，读取 32 位为 12345678H。读取宽度决定需要取几个格子；起始地址不变，结果也可能完全不同。

x86 数据定义：DB 每项 1 字节，DW 每项 2 字节，DD 每项 4 字节。字符串的字符按书写顺序逐字节保存；多字节整数内部按小端序保存。C 数组元素顺序连续，但独立变量的先后、对齐填充须以实际编译布局为准。

13｜容量计算、地址范围与芯片扩展

Week3-Tutorial-Chapter2 with solution.pdf · PDF 第 18 页

存储扩展有两个独立方向：位扩展增加“每个地址存几位”，字扩展增加“总共有几个地址”。先确定目标组织，再分别计算两个方向，能避免把 bit 和 byte 混在一起。

芯片 N×w → 目标 M×W：位扩展 W/w 片并联为一组；字扩展 M/N 组；总片数 (M/N)×(W/w)。这里要求整除且芯片组织相容。
  • 位扩展：同组芯片共用地址和片选，各自接到不同数据位。
  • 字扩展：各组共用低位地址，用高位地址译码产生互斥片选。
  • 非复用地址：N=2ⁿ 个位置需要 n 根地址线；数据线有 w 根。
  • 行列地址复用 DRAM：同一组引脚分时送行号与列号。例如 4M=2²² 个位置，可用 11 根地址引脚分两次传送 22 位地址。
  • 连续范围容量：末地址−首地址+1 个编址单元。末地址=首地址+单元数−1。只有在按字节编址时，单元数才直接等于字节数。

128K×4 芯片含 128K 个 4 位单元，容量是 64KiB；若题目地址逐单元编号，末地址要加 128K−1，不能加 64K−1。系统按字节编址与芯片自身单元编号须分别说明。

14｜8086 分段：逻辑地址到物理地址

Week4-Lecture-Chapter2.pdf · PDF 第 51 页

8086 的寄存器是 16 位，但地址总线为 20 位。它把一个段值左移 4 位形成段基址，再加 16 位偏移，从而用段:偏移表达访存位置。这个机制也直接说明字长与地址宽度可以不同。

实模式公式：PA = (段寄存器 × 10H) + EA。8086 物理引脚最终只输出低 20 位；本册例题均未跨 1MiB 回绕。
  • 取指默认 CS:IP；普通数据大多用 DS:EA；带 BP 的 8086 内存寻址默认 SS；栈操作使用 SS:SP。
  • 同一物理地址可以有多个逻辑地址：段值增加 1，偏移减少 10H，和保持不变（前提是偏移仍在范围内）。
  • 段基址按 16 字节对齐；段内偏移范围 0000H–FFFFH，因此单段最多 64KiB。不同段可以重叠、分开或首尾相接。
  • 80386 的保护模式涉及描述符及可选分页，不能直接套用实模式“段×16”的公式。课件中分页和虚拟地址深入内容标为扩展。

例如 1C8B:011C → 1C8B0H+011CH=1C9CCH，也可写成 1C9C:000C。

15｜总线：把部件连接成可工作的系统

Week5-Lecture-Chapter3.pdf · PDF 第 5 页

寄存器和内存已经能保存数据；总线让它们交换数据。多部件共用一组线路能减少连接成本，也意味着同一时段必须协调谁负责发送、谁负责接收。

总线携带的信息本课常用理解
数据总线 DB数据或指令位读时流向 CPU，写时流出 CPU；通常双向
地址总线 AB目标位置编号由当前总线主设备给出地址；DMA 时主设备可以不是 CPU
控制总线 CB读、写、有效、应答、请求、授权、时钟等不同信号有不同方向和有效电平

内部/外部总线按连接范围分类；并行/串行按传输方式分类；点对点/多点/菊花链按拓扑分类；专用/时分复用按线路是否分时承担地址和数据分类。这些是不同维度，可以组合描述。

共享总线的优点是接线与扩展方便；局限是总带宽竞争及负载、长度、时序限制。同步总线按公共时钟采样；异步总线靠请求和应答握手。多主设备需要仲裁：先请求、获得授权、再使用、最后释放；优先级和公平性会影响等待时间。

16｜读写过程与微操作：一条指令拆成小动作

Week5-Lecture-Chapter3.pdf · PDF 第 45 页 Week5-Lecture-Chapter3.pdf · PDF 第 61 页

一次读操作先确定地址，再发读控制，等数据有效后接收；一次写操作先提供地址和数据，再发写控制让目标保存。地址线回答“去哪”，数据线回答“传什么”，控制线规定“何时传、如何传”。

过程典型步骤
读内存MAR←地址 → 地址上总线 → Read 有效 → 等数据/应答 → MDR←数据 → Read 撤销
写内存MAR←地址、MDR←待写数据 → 地址/数据上总线 → Write 有效 → 等保存/应答 → Write 撤销
微操作类别寄存器传送、算术、逻辑、移位；R2←R1 表示把 R1 的值复制给 R2

微操作是描述内部动作的层次。教学模型里的取指可以写成 MAR←PC；MDR←M[MAR]；IR←MDR；PC←PC+指令长度。实际处理器可以重叠、拆分或采用不同内部实现；不能把所有指令都当成固定相同的几个时钟。

19｜寻址模式：区分立即数、地址与内容

Week7-Lecture-Chapter5.pdf · PDF 第 4 页

模式例子取数过程
寄存器直接MOV AX,BXAX←BX
立即MOV AX,1234HAX←常量 1234H

寄存器间接MOV AX,[BX]EA=BX
寄存器相对/带位移MOV AX,[BX+10H]EA=BX+10H

21｜栈：后进先出与 PUSH / POP

Week6-Lecture-Chapter5.pdf · PDF 第 18 页 Week8-Lecture-Chapter5.pdf · PDF 第 14 页

栈只在栈顶一端读写，最后压入的值最先弹出。8086 的栈位于 SS 段，SP 保存栈顶偏移，按字入栈时向低地址增长。小端序仍然成立。

8086 PUSH word：SP←SP−2，再把 16 位值存入 SS:SP。POP word：先从 SS:SP 读值，再 SP←SP+2。

若 SP=0006H，PUSH AX 会把 SP 改成 0004H，AX 的低字节写在 SS:0004H，高字节写在 SS:0005H。随后 POP BX 会读回同一字，SP 回到 0006H。POP 只是移动栈顶，不会自动把旧内存清零。

“各条独立执行”表示每条都从原始寄存器与内存开始；“连续执行”表示前一步的变化进入下一步。CALL/RET 可通过栈保存/恢复返回地址，中断还涉及 FLAGS 等现场；这解释了栈对程序控制的重要性。8086 普通 PUSH/POP 不支持 8 位寄存器操作数。

23｜BCD 加法与 DAA 校正

Week8-Lecture-Chapter5.pdf · PDF 第 54 页

压缩 BCD 用每个半字节表示 0–9；二进制加法器却在 15 后才进位。因此两个 BCD 相加后，低位或高位可能暂时不是合法十进制数字，需要 DAA 把二进制进位规律改成十进制进位规律。

DAA 紧跟作用于 AL 的压缩 BCD 加法。先保存 ADD/ADC 后的旧 AL 与旧 CF：若低半字节>9 或 AF=1，加 06H；若旧 AL>99H 或旧 CF=1，再加 60H。全部保留低 8 位；AF/CF 表示相应十进制校正与进位。OF 未定义。

例如 56H+72H=C8H。低半字节 8 虽然合法，但前面 6+2 没进位；旧 AL=C8H>99H，因此加 60H 得 28H，并产生 CF=1，表示十进制 128。56+65 则先得到 BBH，低位加 6、高位加 60H，最终为 21H、CF=1。

多字节 BCD 从低有效字节开始 ADD→DAA，高有效字节用 ADC→DAA 接收十进制进位。非压缩调整指令 AAA/AAS、乘除调整 AAM/AAD 与减法 DAS 在课件中出现；后段明确强调只掌握 DAA，本册将其余作为扩展列出。

25｜异步串行帧：起始位、数据、校验、停止位

Week7-Lecture-Chapter7.pdf · PDF 第 31 页

串行链路一次发送一位。异步传输不把时钟线一起送出，而是让收发双方约定速率和帧格式，用起始位标出每个字符的开头。

逻辑帧：空闲 1 → 起始 0 → 数据 d0,d1,…（LSB 先发）→ 可选奇偶校验位 → 停止 1。7 位数据加偶校验时，校验位让“7 个数据位+校验位”的 1 总数为偶数。
  • 求发送序列：先写字符的 7 位 ASCII，拆出 d0 到 d6，再求校验位。
  • 由波形解码：先定位起始位，按每位中心读取数据，最后把 LSB-first 序列翻回常规 MSB-first 数字。
  • 校验不包含起始/停止位；偶校验只保证奇数个位翻转能被检测，不能纠正错误，也不能保证检出偶数个位翻转。
  • RS-232 的物理电压极性与逻辑图不同：mark/逻辑 1 对应负电压，space/逻辑 0 对应正电压。画图时明确用逻辑电平还是实际电压。

若约定 1 起始+7 数据+1 校验+1 停止，共 10 位。位速率为 R bit/s 时，字符速率为 R/10 character/s；7 位有效负载效率为 7/10。

26｜中断、优先级与 8259 级联

Week7-Lecture-Chapter7.pdf · PDF 第 62 页 Week7-Lecture-Chapter7.pdf · PDF 第 86 页

轮询要求 CPU 反复检查状态；中断让设备在需要处理时发出通知。CPU 接受中断后保存必要现场，执行中断服务程序 ISR，再恢复现场继续原程序。中断优先级用于决定多个待处理请求的先后。

  • 8086 的 INTR 是可屏蔽外部中断，受 IF 控制；NMI 是不可屏蔽中断，固定类型 2。软件 INT n 用指令显式触发。
  • 8086 中断入口保存 FLAGS、CS、IP 并清 IF/TF；中断向量 n 的入口偏移和段地址放在物理 4n 与 4n+2 处；ISR 另行保存自身使用的通用寄存器，IRET 返回。
  • 菊花链用串联应答实现位置优先；并行优先电路或可编程中断控制器能够按规则选择请求。不要把 IF 当成所有异常或所有中断的总开关。
一片 8259 有 8 路 IR 输入。1 个主片最多连接 8 个从片，每个从片提供 8 路外部请求，完全级联最多 64 路。若接 s 个从片，则外部请求数=(8−s)+8s=8+7s，0≤s≤8。不能把完整级联写成 8+8×8=72。

课件 Chapter 4 的中断段落标为理解性自学；Chapter 7 特别要求掌握 8259 级联数量计算。两处范围说明应按各自语境阅读。

DMADMA 控制器在设备与内存之间直接传送CPU 设置地址、长度、方向、模式；完成后通常收到中断
I/O 通道/处理器可执行通道程序的专用控制器CPU 启动通道程序，控制器处理更复杂的 I/O 流程

DMAC 先请求总线，获得授权后生成地址和读写控制，完成传输后释放总线。突发模式连续传一块，效率高但会占用总线较久；周期窃取每次传一个或少量单位后让出总线，使 CPU 和 DMA 交错访问。CPU 能否继续运行取决于它是否需要被占用的资源。

DMA 不等于 CPU 完全不参与：初始化和完成处理仍然需要 CPU；它省去的是每个数据单位都由 CPU 指令搬运。通道在 DMA 之上进一步承担命令序列、状态处理等工作。Chapter 7 中除串行帧和 8259 指定页外，其余主要列为了解/自学。
